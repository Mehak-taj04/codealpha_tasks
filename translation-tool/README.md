\# Language Translation Tool



A simple web app built with Streamlit that translates text between languages using the deep-translator library (MyMemory backend).



\## How to run

1\. Install dependencies: `pip install -r requirements.txt`

2\. Run the app: `streamlit run app.py`

3\. Open the browser tab that appears (usually http://localhost:8501)



\## Features

\- Select source and target language from dropdowns

\- Translate button with error handling

\- Copy-ready output box
